# mctrace

[mctrace](https://github.com/jakob-garde/mctrace) is a visualization tool built on top of a ported/re-furbished version of McStas, 
an open-source neutron-scattering Monte Carlo ray-tracing simulation package, developed since 1997.

The current software is a demo / vertical slice of my re-furbishing of the simulation core systems
infrastructure, and utilizes and validates code generated by the
[mcparse](https://github.com/jakob-garde/mcparse) project, without relying on any of the
original or current tooling.

[Download Windows zip](https://github.com/jakob-garde/mctrace/raw/refs/heads/main/release/x64-win/mctrace-0.1.0.zip)

The project's main purposes are:

- Wrap the physics components in a generic and visualization-friendly header, enabling modularity and physics code exporting to any C++ project
- Provide an alternative instrument-based component initialization method, using 4x4 affine transformation matrices
- Greatly reduced dependencies in terms of libraries and build systems
- Wrap the entirety of the McStas static sim libraries into easily-inlcuded header-only libraries, simcore.h and simlib.h
- Enabling a tight development loop with a very low turn-around time
- Provide a first-order validation of the parsing and code generatation provided by [mcparse](https://github.com/jakob-garde/mcparse)

McTrace demonstrates how to build high-level functionality directly on top of low-level C
simulation code, making simulation intrinsics available on the tool level.
Thus, mctrace demonstrates the improved flexibility and speed that becomes possibly by writing high-level tools in C/C++.

The visualization is writte from-scratch, only relying on a thin platform layer (glew/glfw/OpenGL). 
This makes it nearly as portable as the core particle propagaion / Monte-Carlo simulation code itself.

### Disclaimer

The current project mcparse is a tech demo written independently. For the official McCode simulation
project for neutron- and x-ray scattering instrumentation, see [mccode.org](https://mccode.org/).

### Support

The example is PSI_DMC and its 15 components. Further porting of instruments and components
is straight-forwardy - please reach out to me on jakob.garde@gmail.com for further information.
