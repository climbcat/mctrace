# mctrace

The McTrace project is part of a re-imagining of mcstas core functionality, focusing
on the simulation engine and 3D visualization.

McTrace is a visual physics simulation tool for neutron-scattering, which uses the McStas
components and core simulation code. It enables many thousands of lines of physics
simulation code written since 1997, without relying on any of the original tooling.

This project demonstrates the viability and benefits of a partial re-implementaion of the
mcstas core, while keeping the many thousands of lines of tested and verified physics code
intact, making them available through code generation and modularity.

The project's main purposes are:

- Validate code generated by the [mcparse](https://github.com/climbcat/mcparse) project
- Provide an alternative instrument-based component initialization method, using 4x4 affine transformation matrices
- Wrap the physics components in a generic and visualization-friendly header, enabling modularity and physics code exporting to any C++ project
- Greatly reduce dependencies in terms of libraries and build systems
- Wraps the entirety of the McStas static simulation libraries into easily-inlcuded header-only libraries, simcore.h and simlib.h
- Enabling a tight development loop with a total turn-around time below one second

McTrace demonstrates how to build high-level functionality directly on top of low-level C
simulation code, making simulation intrinsics available on the tool level.

This gives many new potential capabilities as compared to the traditional, process-IO approach which
interfaced with the file system and std-out. Thus, McTrace demonstrates the improved
flexibility and speed of high-level tools written in C/C++.

With these working software context examples, it becomes relatively easy to implement new features that include the McStas simulation core, including custom simulations strategies, instrument editors, visual run-time monitoring, and highly dynamic or data-dependent component-configuration patterns.

Code generation by a custom parser of the McStas DSL is implemented in another repository:

- Parsing and code generation: https://github.com/climbcat/mcparse

### Current level of support

Runtime simulation is currently supported by 14 tested components and one instrument, which were tested running
on the modernized, C++-compliant engine.

Further ports are straight-forward to do, however, new explorations were prioritized currently.

For the official McCode simulation project for neutron- and x-ray scattering instrumentation, see [mccode.org](https://mccode.org/).
